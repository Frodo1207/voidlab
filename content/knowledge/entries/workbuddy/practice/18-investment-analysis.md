投资分析最容易“看起来很专业但长期没用”：你能写出一篇像研报的长文，但下一次看另一个标的时，你又换了一套口径。最后你无法横向比较，也无法复盘“自己的判断到底准不准”。

这篇的目标是把投资分析做成**日常化系统**：每次都用同一结构输出、同一口径比较、同一方式追踪结论，最终你得到的不是几篇文章，而是一组能持续更新的判断记录。

## 一句话结论

把投资分析做成日常，你只需要三件事：**固定模板、固定口径、固定回填**。模板保证可比较，口径保证不自欺，回填保证你能从结果里学到规律。

## 适用对象

- 你经常研究标的/赛道/公司，但输出不可比较、不可复盘
- 你想把“看过的东西”变成自己的判断体系，而不是一次性消费
- 你希望 WorkBuddy 帮你做资料整理与结构化输出，但你要保留最终判断权

## 前置条件

### 1) 明确“分析对象”是什么

不同对象的口径完全不同。至少要先选一种：

- 单一公司（股票/私募标的/竞品公司）
- 行业/赛道（趋势、格局、关键变量）
- 策略/主题（例如“AI 应用层机会”“消费复苏”）

### 2) 给它一个稳定工作区

投资分析的输入材料通常很多，必须把边界收在一个目录里，避免跨项目串料：

```txt
investment/
  input/
    source_links.md       # 原始链接清单（最重要）
    notes_raw.md          # 摘要/摘录（可选）
    financials.xlsx       # 财务数据（可选）
  output/
    memo_v1.md
    memo_v2.md
    checklist.md
  tracking/
    thesis.md             # 核心观点（可更新）
    catalysts.md          # 催化与验证点（可更新）
    risks.md              # 风险清单（可更新）
    log.md                # 回填记录（定期更新）
  provenance.md           # 可选：关键结论追溯
```

## 最短路径（可验收）

第一次不要写“研报”，只做一个 2 页内的投资 memo，并强制包含“下一步验证点”。

交付物：

- `output/memo_v1.md`（固定结构）
- `tracking/thesis.md`（一句话核心观点 + 3 条支撑）
- `tracking/catalysts.md`（验证点与触发条件）
- `output/changes.md`（本次更新记录）

验收标准：

- 任何结论都要么有来源链接，要么标“待确认”
- 必须写清楚“如果我错了，会先在哪里被证伪”

## 典型输出结构

- 标的概览
- 当前判断
- 支撑依据
- 风险点
- 后续观察项

这 5 段本质上就是“结论 → 依据 → 反证 → 下一步”。只要结构固定，你就能把不同标的放进同一框架里比较。

## 为什么要模板化

因为投资分析最怕每次都换口径，最后无法比较。

更现实的原因是：你写得再漂亮，只要没有**持续回填**，它就只是一次性文章。模板化的真正价值是让你能持续做三件事：

- 跟踪：你的核心观点是否仍然成立
- 对比：不同标的为什么不一样
- 学习：你过去的判断哪里错、为什么错

## 关键步骤拆解

### 步骤 1：先写“观点”，再做资料堆栈

很多人把投资分析写成“资料汇总”。更稳的做法是先写一个可证伪的观点：

- 我认为：{一句话判断}
- 因为：{3 条可验证依据}
- 我可能错在：{2 条反证路径}

观点先行，会反过来指导你该查什么资料、该忽略什么资料。

### 步骤 2：把“依据”写成可以追溯的证据卡片

每条依据至少包含：

- 断言：你认为发生了什么
- 证据：哪篇材料/哪段数据支撑
- 影响路径：它如何影响结果（增长/利润/估值/风险）

你可以用 `provenance.md` 或者在 memo 中直接带链接。

### 步骤 3：把“风险”写成可触发的监控项

风险不要写成“宏观不好”这种大词，要写成触发条件：

- 风险：{会发生什么}
- 触发信号：{什么数据/事件出现就算发生}
- 应对动作：{发生后怎么办}

### 步骤 4：把“后续观察项”写成待办清单

后续观察项必须是行动句式，而不是“继续关注”：

- 去读：哪篇公告/哪份财报/哪次发布会
- 去对比：谁的产品/谁的价格/谁的渠道
- 去验证：哪条指标/哪次用户调研/哪项实验

## 可复用模板

### 模板 A：投资 memo（output/memo_v1.md）

```md
# 投资 memo：{标的/主题}（YYYY-MM-DD）

## 标的概览
- 一句话定位：
- 商业模式：
- 关键数据口径（你采用的统计范围）：

## 当前判断（一句话 + 置信度）
- 判断：
- 置信度：高 / 中 / 低
- 我会被什么证伪：

## 支撑依据（<= 5 条）
1) 断言：  
   证据：{链接/数据/引用}  
   影响路径：  

## 风险点（触发条件）
- 风险： | 触发信号： | 应对动作：

## 后续观察项（可执行）
- 行动： | 为什么： | 截止：
```

### 模板 B：跟踪回填（tracking/log.md）

```md
# 判断回填日志

## YYYY-MM-DD
- 更新事件：
- 对 thesis 的影响：增强 / 削弱 / 证伪
- 我当初错在哪里（如有）：
- 下一步动作：
```

### 模板 C：WorkBuddy 任务说明（可直接复制）

这段仍然按“目标/输入/动作/约束/输出/验收”的可验收写法来写，保证你能检查它有没有做对。[$TRAE_REF](https://workbuddy.homes/bluebook/%E7%AC%AC%E4%B8%80%E7%AF%87%20%E4%BD%BF%E7%94%A8%E6%89%8B%E5%86%8C%EF%BC%9A%E5%85%88%E6%8A%8A%20WorkBuddy%20%E7%94%A8%E8%B5%B7%E6%9D%A5/%E7%AC%AC%204%20%E7%AB%A0%20%E5%BF%AB%E9%80%9F%E5%AE%8C%E6%88%90%E7%AC%AC%E4%B8%80%E4%B8%AA%20WorkBuddy%20%E4%BB%BB%E5%8A%A1/)

```txt
目标：基于 input/source_links.md 的材料，产出一份可比较、可追踪、可回填的投资 memo，并拆出 thesis/catalysts/risks 三个跟踪文件。

输入：
- input/source_links.md（必须使用；每条材料都要能追溯）
- input/financials.xlsx（如有）

动作：
1) 先给出一句话判断 + 置信度 + 证伪条件（不要先堆资料）
2) 用固定结构写 output/memo_v1.md（概览/判断/依据/风险/观察项）
3) 生成 tracking/thesis.md（核心观点与支撑）
4) 生成 tracking/catalysts.md（验证点与触发条件）
5) 生成 tracking/risks.md（风险与监控信号）

约束：
- 不要写研报式长文；memo 控制在 2 页内
- 所有关键结论必须附来源链接；无法确认就标“待确认”
- 风险必须写触发信号；不要用空泛大词

输出：
- output/memo_v1.md
- tracking/thesis.md
- tracking/catalysts.md
- tracking/risks.md

验收：
- 我能用同一模板对比另一个标的（结构稳定）
- 我能清楚知道“下一步要验证什么”（观察项可执行）
- 我知道我会被什么证伪（证伪条件明确）
```

## 常见坑与排查

- 写成资料汇编：把“当前判断 + 证伪条件”提前到第一段
- 风险写成情绪：强制改成“触发信号 + 应对动作”
- 观察项写成“继续关注”：改成“去做什么/去读什么/去验证什么”
- 每次口径都不一样：把 memo 模板写死，并用 log.md 回填，避免自我叙事
