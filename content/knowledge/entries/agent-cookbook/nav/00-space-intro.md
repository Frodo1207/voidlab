## 一句话结论

这套课默认你已经有一点代码基础。你不需要一开始就会某个 Agent 框架，但最好至少写过一点脚本、看得懂基本文件结构，也知道怎么运行一个最小项目。因为这套课不会停留在概念介绍，而是会一路把你带到真正动手搭建系统。

## 这门课会带你做到什么

最终这套课会带大家走到一个明确的终点：做出一个**多 Agent 对战系统**。你会在这个过程中，逐步学会下面这些东西：

- 如何从 0 到 1 搭建一个最小 Agent
- 如何让 Agent 带着状态、工具和目标运行
- 如何把一个 Agent 扩展成多 Agent 系统
- 如何理解 Agent 之间的协作、博弈和 `A2A` 交互

也就是说，这套课不是停在“会调用一个模型”，而是会把你带到“能设计一个多角色系统”。

## 默认前置要求

- 有一点代码基础
- 愿意自己跑项目、改文件、看报错
- 对 AI 和 Agent 有兴趣，但还没真正搭过完整系统

如果你完全没有写过代码，也从没跑过最小项目，这套课会偏快。因为这里默认你已经能接受“边学概念，边看代码，边推进系统”这种节奏。

## 这套课的大致路径

前面几章会先把大语言模型、Agent 和最小示例讲清楚，然后逐步带到：

- 第一个最小 Agent
- 第一个可验收 Agent
- 多 Agent 对战系统

这条路不会一上来铺很多框架和名词，而是一直围绕最后那个系统目标往前推进。
