# 媒体与封面

## 适用场景

当任务与这些动作有关时，读这一份：

- 上传封面
- 查询媒体列表
- 给文章 / 活动 / Builder 回填封面

## 当前项目真实链路

虽然项目里存在 `MinIO` 配置，但当前线上真实媒体链路仍以本地 `uploads` 为主。

当前常见做法有两条：

### 路径 A：媒体接口上传

- `POST /api/v1/media/upload`

如果成功，返回：

- `object_url`

再把这个地址写回：

- `cover_url`

### 路径 B：回退到 uploads

如果媒体接口异常，可回退：

1. 直接把图片放到服务器 `uploads`
2. 确认公网可访问
3. 回填 `cover_url`

## 使用建议

- 封面优先横版
- 不要在图里塞标题字
- 封面生成后先确认可访问，再写回资源

## 当前已知问题

历史上 `media_assets` 可能出现列缺失问题，例如：

- `file_size`
- `uploaded_by`

如果再遇到上传失败，不要只看 token，先检查数据库迁移是否跟上。
