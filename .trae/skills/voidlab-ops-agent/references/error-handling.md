# 错误处理

## 常见错误

### 401

含义：

- token 缺失
- token 无效
- token 已停用

处理：

- 提醒用户更换有效 token

### 403

含义：

- token 有效
- 但 scope 不够

处理：

- 明确告诉用户缺的是哪类权限
- 不要盲目重试

### 400

含义：

- payload 不完整
- 状态流转不合法
- 必填字段缺失

处理：

- 先读当前对象
- 按完整 payload 重发

### 5xx

含义：

- 服务抖动
- 代理异常
- 数据库问题

处理：

1. 先确认 `/healthz`
2. 再确认目标接口是否偶发失败
3. 如果是媒体上传，可先回退到 `/uploads`

## 当前项目特别提醒

- `media/upload` 报错时，不要第一时间怀疑 token
- 先检查：
  - `media_assets` 表结构
  - 上传接口是否偶发 `502`
  - 是否可直接回退到 `uploads`
