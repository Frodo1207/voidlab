# 运营总览

这个 skill 的定位不是“资料堆”，而是“运营执行代理”。

它当前统一覆盖四类运营动作：

- 文章运营
- 活动运营
- Builder 运营
- 媒体上传与封面回填

## 核心原则

### 1. 一律优先走 agent token

所有受保护请求都优先使用：

```bash
Authorization: Bearer $VOIDLAB_AGENT_TOKEN
```

不要默认借用人工管理员会话。

### 2. 写操作前先握手

至少先做：

1. `GET /healthz`
2. `GET /api/v1/auth/me`
3. 目标模块一次只读检查

### 3. 默认先建草稿

如果用户没有明确说“直接发布”，默认先建：

- `draft`

### 4. 先读再改

如果是更新类任务，不要盲写。  
应先读取当前对象，再合并变更并写回。

## 当前项目特别约定

- 资讯正文优先使用 `Markdown`
- 资讯标题默认不要再带 `AI HOT｜`
- 当前媒体链路真实落点仍以 `uploads` 为主
- 媒体接口异常时允许回退到 `/uploads`
