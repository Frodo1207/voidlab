## 这套课主要参考什么

这套 Space 当前主要参考三类来源：

- 官方产品与 API 文档
- 社区开源项目与教程
- 我们自己的实践重组与案例设计

## 当前重点参考

- `datawhalechina/hello-agents`
- 各类 Agent 宿主官方文档（如 Codex、Trae 及同类工具）
- MCP / 工具调用相关官方资料

这些来源分别承担不同作用。`hello-agents` 更像课程编排和案例启发的参考，宿主官方文档主要用于解释实际工作台怎么运作，MCP 与工具调用资料则用来补足“Agent 怎样真正碰到外部世界”这条主线。

## 使用原则

- 不原样搬运外部内容
- 优先重写成任务、模板、交付物与验收标准
- 关键概念和能力边界保留引用来源

## 这套课怎么处理外部材料

外部材料在这里不是终点，而是原料。我们不会把某个仓库、某篇教程或某份官方文档直接搬进来，而是先判断：它到底在解决哪类问题，再把它重写进更适合零基础读者的路径里。

所以你在这套课里看到的很多内容，虽然参考了外部来源，但最终呈现方式往往会被重组为：

- 一个更短的概念入口
- 一份更容易复用的任务模板
- 一个更容易检查的交付物定义
- 一组更贴近真实使用场景的案例

## 引用边界

为了让整套课既能站在已有资料上，又保持自己的结构，我们会尽量遵守下面几条边界：

- 外部来源用于校正概念、产品能力和案例方向
- 本地内容负责重组学习路径、任务结构和验收方式
- 涉及官方产品能力时，优先以官方文档口径为准
- 涉及案例设计时，以这套课自己的教学目标为准，不追求逐字对应原文

## 为什么这一页值得保留

一套零基础教程最容易出的问题，不是资料不够，而是资料太散。把来源和重组原则单独放一页，作用不是“列参考文献”，而是告诉读者：这套课不是凭空写出来的，但它也不是外部资料的拼贴。

## 为什么要写这一页

因为这套课不是框架手册，也不是社区项目镜像。它更像一套零基础 cookbook：参考外部材料，但重心是把知识重组为“更适合上手开发”的路径。
